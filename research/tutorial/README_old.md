# Introduction to AWS SageMaker AI

In this tutorial, we present a practical example of how we used AWS SageMaker AI in our project. The goal is to demonstrate the main functionalities of SageMaker, including:

- Data acquisition and preparation  
- Model training  
- Model deployment for inference  

This tutorial follows a simplified end-to-end machine learning workflow using SageMaker.

---

## Objectives

- Understand how AWS SageMaker AI supports the ML lifecycle  
- Learn how to prepare and upload data to the cloud  
- Train a machine learning model using SageMaker  
- Deploy the trained model as an API endpoint  
- Perform predictions using the deployed model
